## Sobre o site

Portfólio pessoal em HTML, CSS e JavaScript puros, sem frameworks nem etapa de build.

- Avatar 3D com seletor de humor (troca de expressão)
- Site e currículo em três idiomas: português, inglês e espanhol
- Currículo em A4 que pode ser baixado em PDF direto do navegador
- Formulário de contato via FormSubmit
- Efeitos sonoros de interface, que podem ser desligados

## Estrutura

```
index.html        página principal
cv.html           currículo (A4, imprimível)
cases/            estudos de caso
assets/           imagens, avatar e mídia
scripts/          i18n, animações e interações
styles/           folhas de estilo
```

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```
npx serve .
```
